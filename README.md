# Face Blur Tracker — плагин для OBS Studio

Видеофильтр для OBS: находит лица в кадре, сопровождает их и размывает (или пикселизирует / закрашивает) только эти области. Работает на любом источнике: камера, захват экрана, окно, сцена.

## Как это работает

```
кадр источника ─► уменьшенная копия ─► поток детектора (YuNet, OpenCV dnn) ─► трекер
       │                                                                        │
       └──────────────► шейдер на GPU (размытие в областях лиц) ◄───────────────┘
```

- **Детектор** — модель YuNet (лежит в `data/models/`), работает на CPU в отдельном потоке и не тормозит рендер OBS. Декодирование выходов модели написано в `src/yunet-detector.hpp`.
- **Трекер** — сопоставление по IoU + alpha-beta фильтр: рамка плавно следует за лицом, экстраполируется между обнаружениями, держится заданное время после потери лица, одиночные ложные срабатывания отсеиваются.
- **Размытие** — на GPU: диск-блюр (48 проб), пикселизация или сплошной цвет, мягкий край.
- Если лиц нет, фильтр ничего не рисует и не нагружает GPU.

## Настройки фильтра

| Параметр | Что делает |
|---|---|
| Режим | Размытие / Пикселизация / Сплошной цвет |
| Сила эффекта | Радиус размытия или размер «пикселей» |
| Запас вокруг лица | Расширяет область (рамка детектора уже головы), по умолчанию 40% |
| Мягкость края | Плавный переход к нетронутому кадру |
| Порог уверенности | Выше — меньше ложных срабатываний, ниже — реже пропуски |
| Максимум лиц | До 16 |
| Держать область после потери | Пока детектор не видит лицо (поворот головы), область остаётся на месте |
| Отзывчивость трекинга | Выше — быстрее следует, но может дрожать |
| Разрешение детекции | Ширина уменьшенного кадра для детектора: 320–960 px |
| Частота детекции | Сколько раз в секунду запускать детектор |
| Рамки детекции | Зелёные рамки для отладки настроек |

Для камеры обычно хватает 480 px и 30 раз/с. Если лица мелкие или далеко, поднимите разрешение до 640–960.

## Установка

Папка `obs-face-blur` (в ней `bin/64bit` и `data`) копируется сюда:

- **Windows:** `C:\ProgramData\obs-studio\plugins\`
- **Linux:** `~/.config/obs-studio/plugins/`

Затем: правый клик по источнику → **Фильтры** → **+** → **Отслеживание и размытие лиц**.

Готовую папку для Linux можно скачать из артефактов последнего запуска во вкладке **Actions** на GitHub.

## Сборка

Нужно: CMake ≥ 3.16, компилятор C++17, **libobs** (заголовки и библиотека из сборки OBS или пакет `libobs-dev`), **OpenCV ≥ 4.5.4** с модулями `core`, `imgproc`, `dnn`.

```
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

В `build/dist/obs-face-blur` появится готовая папка плагина. На Windows DLL от OpenCV должны лежать в `bin/64bit` рядом с плагином.

## Проверки

- `tests/tracker_test.cpp` — логика трекера (запускается в CI).
- `tests/yunet_reference.py` — эталонный декодер YuNet на Python (OpenCV + numpy), по нему сверен C++ код.

## Ограничения

- Детектор лучше всего находит лица анфас и в полупрофиль. При резком повороте головы возможен пропуск на пару кадров, его перекрывают «удержание области» и запас вокруг лица.
- Между появлением лица и размытием бывает задержка в 1–3 кадра. Для критичной приватности держите запас не ниже 40%, а порог уверенности умеренным (≈60–70%).
- Размытие нужно проверять на предпросмотре перед эфиром, особенно при плохом свете, масках и очках.
